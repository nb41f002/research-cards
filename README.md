# 2026 Research Cards · GitHub Pages Package

This is a static, build-free website. All HTML files are self-contained except for Google Fonts and linked external resources.

## Deploy to GitHub Pages

1. Create a GitHub repository.
2. Upload every file in this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Open the GitHub Pages URL after deployment.
